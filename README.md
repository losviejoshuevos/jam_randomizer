# Jam Randomizer

Jam Randomizer — браузерное приложение для создания, редактирования и проведения музыкальных джем-сессий. Генератор собирает гармонию по правилам выбранного стиля, а Stage Mode превращает результат в крупную сценическую карточку с таймером и метрономом.

Текущее состояние проекта — рабочая Funk alpha. Редактор и Stage Mode уже подходят для самостоятельного тестирования, но проект ещё не достиг версии 0.9 для широкого бета-теста среди музыкантов.

## Что работает

### Редактор сессии

- стиль Funk;
- темы A–D с ролями «основная тема», «развитие», «бридж» и «кода»;
- готовые формы ABA, ABAB, ABCABC и ABCD;
- собственная форма из тем A–D;
- независимые тональность, лад, сложность аккордов и гармоническая свобода каждой темы;
- фокус на одной или нескольких темах для выборочной регенерации;
- общая регенерация всех тем с их собственными настройками;
- транспонирование выбранных или всех тем без изменения их гармонической структуры;
- размеры 4/4 и 3/4;
- случайный Funk BPM от 98 до 118 и ручной BPM от 40 до 240;
- случайная или ручная длительность каждой темы в секундах либо квадратах;
- изменение BPM, размера и длительностей без регенерации аккордов;
- ручная замена аккорда из доступного словаря;
- свободный ввод аккордов с подсказками и альтернативными джазовыми обозначениями;
- поддержка расширенных и слэш-аккордов;
- добавление и удаление аккордов, максимум восемь аккордов на тему;
- изменение длительности отдельного аккорда;
- редкое разбиение такта на две половины в размере 4/4;
- локальная история последних десяти карточек;
- восстановление текущей сессии и черновых настроек после перезагрузки.

### Funk Music Engine

- воспроизводимая генерация на основе seed без `Math.random`;
- отдельное управление сложностью надстроек и гармонической свободой;
- приоритет устойчивого грува над частыми функциональными сменами;
- одноаккордовые и двухаккордовые vamp-последовательности;
- основные движения вокруг I, IV и V;
- варианты двух состояний одной тоники: `I7–I9`, `I9–I13`, `i7–i9`, `i9–i11`;
- Dorian `i–IV`, минорный `i7–III9` и тритоновый `i9–♭II9`;
- редкие хроматические полутактовые движения `i–♭II`, `I–♭II` и `v–♭v–iv`;
- не более одного сгенерированного внедиатонического аккорда на сессию;
- полутактовые turnaround чаще используются в темах развития, а не в основной теме;
- валидация длительности, допустимых аккордов, разрешений и структурных инвариантов;
- понятное отображение ступеней относительно выбранного мажорного или натурального минорного лада.

Funk-профиль опирается на характерные приёмы известных записей: статичную гармонию, одно- и двухаккордовые vamp, движение `i–IV`, смену окраски одного корня и короткие хроматические переходы. Подробности находятся в [исследовании Funk-гармонии](docs/funk-harmony-research.md).

### Stage Mode

- полноэкранное представление текущей темы;
- адаптивная сетка от одного до восьми аккордов;
- крупные аккорды и заметные обозначения количества тактов;
- объединённое отображение двух аккордов по полтакта;
- таймер текущей темы;
- автоматический и ручной переход по форме с завершением текущего такта;
- предварительный показ уходящей и следующей темы;
- звуковой метроном с отдельными звуками сильной и остальных долей;
- корректная работа метронома в 4/4 и 3/4;
- регулятор громкости и визуальная пульсация активной карточки;
- экран завершения сессии и повторный запуск;
- приоритет горизонтальной сценической и мобильной развёртки.

## Запуск

Требуется актуальная LTS-версия Node.js с npm.

```bash
npm install
npm run dev
```

- редактор: [http://localhost:3000](http://localhost:3000)
- Stage Mode: [http://localhost:3000/stage](http://localhost:3000/stage)

## Проверки

```bash
npm run lint
npm test
npm run build
```

На текущей итерации проходит 128 unit-тестов. Они покрывают воспроизводимость, гармонические профили, формы A–D, независимые настройки тем, транспонирование, свободный ввод аккордов, длительности, метроном, персистентность и статистические инварианты Funk-генератора на больших выборках seed.

Музыкальное качество дополнительно проверяется вручную: автоматические тесты ограничивают технические и вероятностные дефекты, но не заменяют прослушивание и игру с реальными музыкантами.

## Архитектура

### Music Engine

Музыкальная логика реализована на чистом TypeScript без React, DOM и localStorage.

```text
StyleProfile
→ форма и гармонический ритм
→ функции и стилевые шаблоны
→ римские аккорды
→ реальные символы в тональности темы
→ валидация
→ JamSession
```

Стилевые правила находятся в сериализуемом `StyleProfile`. Это позволяет добавлять Rock, Blues и другие жанры отдельными профилями, не смешивая их музыкальные правила с UI.

### UI

Редактор и Stage Mode работают с готовой доменной моделью `JamSession`. Управление формой, фокусом тем и ручными изменениями находится в React-компонентах, а генерация, транспонирование, рендеринг и валидация — в Music Engine.

### Persistence

Текущая сессия, черновые настройки и история карточек сохраняются через отдельный localStorage-адаптер. Регистрации, базы данных и backend пока нет.

Код вида `FUNK-XXXXX-XXXXX` является локальным идентификатором карточки. Он пока не содержит всю сессию и не позволяет открыть её на другом устройстве без общего хранилища.

## Известные ограничения

- доступен только стиль Funk;
- вероятности генератора требуют дальнейшей настройки после музыкальных тестов;
- история ограничена десятью карточками в localStorage конкретного браузера;
- нет самодостаточной ссылки или файла для переноса карточки;
- код карточки нельзя открыть напрямую по URL или QR;
- нет подключения ведомых экранов и синхронизации между устройствами;
- нет светового мастер-метронома как отдельного сценического элемента;
- нет подсказок для барабанщика, басиста, гитариста, клавишника и вокалиста;
- нет аппликатур и voicings;
- нет автоматического «колеса джема»;
- интерфейс и Music Engine ещё нуждаются в полировке перед beta 0.9.

## Roadmap до beta 0.9

### 1. Завершение редактора и Stage Mode

- дополнительные сессии ручного тестирования;
- исправление музыкальных и визуальных corner cases;
- дальнейшая полировка переходов, метронома и мобильной развёртки;
- экспорт сессии в самодостаточную ссылку или файл;
- пользовательская инструкция.

### 2. Новые стили

- Rock;
- Blues;
- Soul / R&B;
- Jazz;
- отдельный словарь, ритм, шаблоны и музыкальные тесты для каждого `StyleProfile`.

### 3. Сохранение и sharing

- копирование самодостаточной ссылки;
- системное меню «Поделиться»;
- отправка ссылки в Telegram без обязательного бота;
- QR-код для открытия карточки на другом устройстве;
- опциональный Telegram-бот без собственной базы, если данные сессии помещаются в ссылку.

### 4. Ведомые экраны

Ведущий запускает Stage Mode, а остальные музыканты открывают пассивный экран по QR. На ведомые устройства передаются текущая тема и переходы. Мастер-метроном остаётся на одном устройстве; точная межустройственная синхронизация звука не является обязательной для первой версии.

### 5. Автоматическое «колесо джема»

Весёлая кнопка полностью собирает сессию: выбирает стиль, тональность, лад, BPM, сложность, гармоническую свободу, форму, длительности и аккорды.

### 6. Подсказки участникам

- ритмические идеи для барабанщика;
- басовые паттерны;
- ритмика для гитары и клавишных;
- направления для вокальной импровизации;
- аппликатуры аккордов для гитариста;
- voicings для клавишника.

### 7. Beta 0.9

Почти завершённая версия передаётся музыкантам. Основные цели бета-теста — найти странности генератора, проверить читаемость Stage Mode в реальном помещении и собрать новые сценарии использования.

## Git workflow

- `main` — стабильная опубликованная версия;
- `develop` — текущая разработка;
- перед завершением итерации запускаются lint, unit-тесты и production build;
- после ручного тестирования завершённая итерация фиксируется отдельным коммитом.
