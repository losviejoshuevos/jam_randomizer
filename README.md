# Jam Randomizer

Jam Randomizer — браузерное приложение для создания понятных и воспроизводимых карточек музыкальных джемов. Генератор строит гармонию по правилам выбранного стиля, позволяет отредактировать результат и показывает его в полноэкранном Stage Mode.

Текущее состояние проекта — рабочий Funk MVP / alpha. Это уже тестируемый музыкальный инструмент, но ещё не версия 0.9 для внешнего бета-теста.

## Что работает

- первый стиль: Funk;
- мажорные и минорные тональности;
- размеры 4/4 и 3/4, основной приоритет — 4/4;
- сложности аккордов Easy, Medium и Advanced;
- гармоническая свобода Strict, Colorful и Adventurous;
- случайный BPM в диапазоне стиля и ручной BPM от 40 до 240;
- воспроизводимая генерация по seed;
- две связанные темы и форма A → B → A;
- тема B как контрастное развитие темы A;
- редкие смены аккордов по полтакта в 4/4;
- ручная замена каждого аккорда из допустимого словаря;
- изменение BPM и длительности уже созданной сессии;
- локальная история последних 10 карточек;
- Stage Mode с таймером, ручным переходом между темами и экраном завершения;
- предупреждение о переходе длительностью в один квадрат плюс один запасной такт;
- предварительный показ следующей темы перед переходом;
- безопасная работа с повреждённым или несовместимым localStorage;
- адаптивное отображение длинных названий аккордов и крупные обозначения длительности.

Funk-правила основаны не только на функциональной гармонии, но и на анализе известных записей: одноаккордовых вампов, Dorian i–IV, смен окраски 9/13, dominant planing и редких хроматических side-slip движений. Подробности находятся в [исследовании Funk-гармонии](docs/funk-harmony-research.md).

## Запуск

Требуется актуальная LTS-версия Node.js с npm.

```bash
npm install
npm run dev
```

- редактор: [http://localhost:3000](http://localhost:3000)
- Stage Mode: [http://localhost:3000/stage](http://localhost:3000/stage)

## Проверки

```bash
npm run lint
npm test
npm run build
```

На текущей итерации проходит 68 unit-тестов, включая проверки воспроизводимости seed, сложности, гармонической свободы, рендеринга RomanChord, полутактовых смен и структурных инвариантов на больших выборках.

## Архитектура

### Music Engine

Чистый TypeScript без React, DOM и localStorage. Конвейер генерации:

```text
StyleProfile
→ гармоническая форма и ритм
→ функции
→ римские аккорды
→ реальные символы в выбранной тональности
→ валидация
→ JamSession
```

Особенности стиля находятся в сериализуемом `StyleProfile`. Генератор не содержит условий вида `if (styleId === "funk")` и не использует `Math.random`.

### UI

React-компоненты редактора и Stage Mode отображают готовую доменную модель. Музыкальные правила и вероятностные таблицы остаются за пределами UI.

### Persistence

Состояние сохраняется через отдельный localStorage-адаптер. В браузере хранятся текущая сессия, последние настройки и история карточек. Регистрации, базы данных и backend пока нет.

## Известные ограничения

- генератор Funk требует дальнейшего музыкального тестирования и настройки вероятностей;
- полутактовые пары в Stage Mode функциональны, но визуально ещё могут быть улучшены;
- нельзя регенерировать или блокировать только одну тему;
- смена тональности не транспонирует уже открытую карточку;
- нельзя свободно вводить произвольный символ аккорда;
- нет конструктора форм ABAB, ABCABC, ABCD и других паттернов;
- типы Zustand подготовлены, но состояние редактора пока хранится локально в React;
- нет переключателя визуальных тем;
- код карточки нельзя открыть напрямую по URL или QR;
- синхронизации между несколькими устройствами нет;
- приложение ещё не опубликовано как публичная beta 0.9.

## Roadmap до beta 0.9

### 1. Завершение локального редактора и Stage Mode

- регенерация отдельной темы;
- блокировка темы от регенерации;
- транспонирование открытой карточки;
- редактирование длительности отдельных аккордов;
- плавный переход с одновременно видимыми уходящей и следующей темами;
- дополнительная полировка Stage Mode;
- несколько визуальных тем.

### 2. Формы и стили

- настраиваемые паттерны ABAB, ABCABC, ABCD и другие;
- второй стиль: Rock;
- третий стиль: Blues;
- отдельное музыкальное тестирование каждого StyleProfile.

### 3. Автоматическое «колесо джема»

Кнопка должна полностью собирать сессию: выбрать стиль, тональность, лад, BPM, сложность, гармоническую свободу, форму, длительности и аккорды.

### 4. Подсказки участникам

- ритмические идеи для барабанщика;
- басовые паттерны;
- ритмика для гитары и клавишных;
- направления для вокальной импровизации;
- аппликатуры аккордов для гитариста;
- voicings для клавишника.

### 5. Метроном

- звуковой метроном;
- крупный световой метроном в Stage Mode;
- в дальнейшем — синхронизация метронома между устройствами.

### 6. QR и совместная сессия

Ведущий создаёт комнату, остальные музыканты открывают её по QR, после чего темы и метроном синхронно меняются на всех устройствах. Этот этап потребует backend, WebSocket-соединений и синхронизации по серверному времени. Music Engine при этом может остаться клиентским и независимым.

### 7. Beta 0.9

Версия передаётся реальным музыкантам после реализации согласованных продуктовых идей. Основные цели бета-теста — найти музыкальные корнер-кейсы генератора, проверить читаемость Stage Mode и собрать новые сценарии использования.
